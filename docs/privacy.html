privacy

guiport.dev is a static site that loads one analytics script, a self-hosted Umami instance at insights.applifyer.com. It counts visits so we can tell which pages people actually read and which install path they came from. The numbers are aggregate totals in our own dashboard, not something used for advertising or cross-site profiling.

For each visit we record the page you visited, the page that referred you, your browser language, your device screen size, and an approximate location (country) derived from the request. Analytics runs without cookies. Only the standard campaign tags utm_source, utm_medium, utm_campaign, utm_term, and utm_content are retained for attribution; other query parameters and URL fragments are removed from tracked page addresses.

You can opt out. If your browser sends a Do Not Track signal, no pageview is sent at all. A content blocker that blocks insights.applifyer.com works too. The site looks and behaves the same either way; nothing on it depends on analytics.

website only. This notice covers guiport.dev in the browser. This website configuration does not change CLI/MCP telemetry.
