# guiport

guiport lets coding agents inspect and operate desktop applications through its
CLI and MCP interface. Keep public platform claims aligned with implemented
capabilities and the documented support matrix.

The SEO intake board covers the website in `docs/`. It may fix reproduced
metadata, crawl, navigation, broken-link and website accessibility defects.
Preserve installation commands and native application behavior. Native features,
licensing changes and new data collection require separate product review.

Verify website changes through HTML and sitemap checks plus a real browser.
Do not start a paid native build to validate a website-only change. Publishing
uses the dedicated Linux GitHub Pages workflow described in `docs/website.md`.
